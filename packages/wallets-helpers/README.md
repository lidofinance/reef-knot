# Wallets Helpers

Shared runtime helpers and TypeScript contracts for Reef Knot wallet adapters.

```ts
import type {
  WalletAdapterArgs,
  WalletAdapterData,
  WalletAdapterIcons,
  WalletAdapterType,
} from '@reef-knot/wallets-helpers';
```

This package is independent of the Reef Knot UI and the default wallet catalog.
